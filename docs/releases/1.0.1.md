# Echo 1.0.1 — Windows desktop

## 下载与安装 / Download and install

下载本页 Assets 中的 **Echo-Setup-1.0.1.exe**，运行安装向导，再从开始菜单打开 Echo。无需克隆代码或安装 Python、Node.js、FFmpeg。进入「设置」填写所选服务的 API Key，即可使用对应的 AI 功能。

Download **Echo-Setup-1.0.1.exe** from Assets, run the installer, and launch Echo from the Start menu. No source checkout, Python, Node.js, or separate FFmpeg installation is needed. Add your chosen provider's API key in Settings.

- Windows x64 installer; approximately 194 MiB.
- Cloud AI features require internet access and the relevant provider credentials.
- Local model servers and model weights are separate installations.
- The installer is unsigned; Windows may display an unknown publisher warning. SHA256SUMS.txt contains checksums for the download assets.

## Changes

- Standalone Electron desktop shell with an isolated, frozen FastAPI backend and bundled audio tools.
- Startup diagnostics, local profile isolation, and backend shutdown handling.
- Qwen 3.5 LiveTranslate fixes for multi-sentence transcription and audio ordering.
- Model picker text clipping fixes.
- PAL page tests resolve the Daily SDK mock before starting calls, preventing
  the cold-cache packaging failure observed after reinstalling dependencies.

Verified on the Windows build machine with Python 3.12 and Node.js 22:

- Backend: 946 tests and 99 subtests passed.

- Frozen backend smoke check passed.
- Actual NSIS payload extracted and launched successfully with a fresh profile and a path containing Chinese characters and spaces. Checks cover rendered chat, IPC, local HTTP assets, bundled FFmpeg/FFprobe, and shutdown.

## Known limitations / 已知限制

- Qwen LiveTranslate 的累计原文分支目前不会完整写入会话记录及长期记忆；实时显示修复不代表历史记录已修复。
- Qwen LiveTranslate cumulative source transcripts are not fully persisted to session history or long-term memory.
- Cloud provider calls and paid features were not exercised by the packaging smoke tests.
- Interactive install/uninstall and clean-VM SmartScreen behavior have not been validated. This release verifies the extracted installer payload.
- Close any Echo development server occupying port 8000 before starting the desktop app. Startup logs: `%APPDATA%/echo-desktop/logs/desktop-startup.log`.

The blockmap and latest.yml assets support the application's update mechanism; ordinary users only need the EXE. Do not download GitHub's Source code archives to install the application.
